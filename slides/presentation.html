Architecture

Plan → Execute → Synthesize

Every broker question runs through a structured agent pipeline with quality checks.

1. Pre-query Brief

Convex assembles ranked listings, regulations, market data, maintenance, and transaction history before the LLM sees the query.

briefs.ts relevance ranking

2. Tool Execution

Flash-lite planner generates 2-5 steps. Pro model calls 10 domain tools: search_listings, get_market_data, search_regulations, get_maintenance_schedule, and more.

agent.ts 10 tools Google Search

3. Quality Gate

7 runtime checks: listing reference, regulation grounding, action steps, revenue impact, cross-property patterns, priority ordering, reference integrity.

Tradeoffs & Roadmap

What shipped, what didn't, and what's next

Shipped

  • Role-aware RBAC: broker, portfolio manager, analyst
  • 8 synthetic properties with 20 listings across 5 types
  • 15 CT real estate regulations for grounding
  • 40 market data points (CoStar, CBRE, JLL, NCREIF)
  • Gemini agent with plan-execute-synthesize + quality gate
  • Evidence upload (images, PDFs, documents)
  • 20-scenario golden eval with automated judge
  • Full audit trail for every agent, listing, and file event

Intentional Tradeoffs

  • No auth integration (picker-based operator sessions)
  • Synthetic data only (no live market feeds)
  • Keyword search for regulations (no GraphRAG)
  • Single-model architecture (Gemini only)
  • Two-region demo (extensible to N regions)

Production Roadmap

  • GraphRAG for regulation dependency chains (Neo4j)
  • Live market data feeds (CoStar / CBRE API)
  • Document intelligence for lease and inspection PDFs
  • Multi-tenant auth with Clerk or WorkOS
  • Golden eval CI gate on every deploy
